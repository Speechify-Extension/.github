## First Look at Speechify Extension

Speechify Extension is for people who already have the article on screen and want to hear it. Speechify gives you playback next to that tab. Speechify Extension does not go looking for pages you did not open. It reads what is in front of you.

Students and home readers can use Speechify Extension in different ways, but the idea stays the same: this tab, this page, a pace you can follow. Speechify Text To Speech stays with that article.

The useful moment is simple. The page is already loaded. You start Speechify. You pause when the sentence matters. You leave the tab where it was so you can read the same line with your eyes.
